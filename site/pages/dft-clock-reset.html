扫描测试不只是把 CLK 接到所有寄存器。移位、捕获、复位和功能模式需要彼此可控，否则一次测试脉冲可能在错误的时刻推进状态，甚至让复位释放顺序失去定义。

OCC 在做什么

OCC（On-Chip Clock Controller）是测试时钟控制结构。教学模型把它抽象成一个安全门控器：

  • 在 Shift 模式放行受控的扫描沿；
  • 在 Capture 模式从功能时钟源沿中放行 launch/capture；
  • 在测试使能关闭、模式不一致或复位有效时保持输出关闭。

真实 OCC 还要处理功能时钟源、测试时钟源、脉冲选择、门控时序、时钟域和约束。这里的两个捕获脉冲只是说明状态机含义，不代表某家 IP 的固定脉冲数量。

本页为了让“复位保护”可观察，明确选择了 resetBlocksClock=true 的教学策略：复位有效时关闭模型输出。复位并不天然意味着所有真实 OCC 都必须关闭时钟；实际芯片应按 OCC 规格、复位同步方式和测试协议决定。

Shift 与 Capture 的边界

Shift 的目标是把数据稳定地推进扫描链，通常关注扫描时钟频率、链长、功耗和 SE 保持时间。Capture 的目标是让功能逻辑产生响应并在目标时刻采样，可能需要 at-speed 功能时钟。

在实验中切换到 Capture 后，必须关闭 SE、保持 Test Enable 并打开“功能时钟源”。每次单步送入一个源沿；第一个被允许的沿标为 launch，第二个标为 capture，后续两个源沿被计数门控挡住。请求 capture与确实存在一个可用时钟源不是同一件事；没有源沿时不会伪造输出，单步和播放禁用。

每组只观察四个源沿。逐沿表记录 SE、TE、RST、放行与否、脉冲角色、计数前后值和还需输出的沿数。选择历史沿会暂停，图中累计圆点、读数与讲解同步回看；继续操作仍从最新状态前进。修改控制条件会重新开始本组，不把新条件套在旧记录上。

“已放行 / 本组预计输出沿”不是频率或物理脉宽。所有边沿序号、圆点间距及播放速度都只是教学表达；本模型不验证无毛刺切换、真实高速波形或扫描触发器的数据捕获值。

门控、测试使能和复位

  • Test Enable 决定测试时钟请求是否进入 OCC；它不是扫描数据。
  • Scan Enable 决定扫描寄存器选择移位路径还是功能路径；它必须在捕获边界满足时序。
  • Reset 有效时，实验模型安全关闭输出，避免复位中的寄存器被测试沿部分推进。

真实芯片可能有同步或异步复位、复位同步器、多个电源域和不同的复位控制策略。复位极性、释放沿和跨域顺序必须以 RTL、库单元和 DFT 约束为准；本页不替用户选择这些实现。

动手顺序

  1. 选择 Shift，保持 SE 和 Test Enable，单步四次观察计数 0→1→2→3→4。
  2. 选择 Capture，关闭 SE 并打开“功能时钟源”，单步四次观察计数 0→1→2→2→2；最后两次有源沿，但没有输出沿。
  3. 勾选“复位有效”后开始新一组，确认即使送入源沿，输出计数仍为 0。
  4. 选择一个旧记录，观察门控和计数回到同一时刻；回看不会改变当前实验。
  5. 关闭 SE 后回到 Shift，观察模式不一致使请求被拒绝。这不表示实际芯片的正常功能时钟也被关闭。

常见误区

误区 更准确的说法
OCC 是一个简单的 AND 门 OCC 还需要模式控制、脉冲协议和时序约束
复位有效时多打几个时钟没关系 复位期间的时钟可能造成部分状态推进或不确定行为
Capture 有请求就一定有 at-speed 脉冲 还需要选定时钟源、门控条件和合法时序
Shift 与 Capture 可以共用同一组约束 二者的频率、SE 边界、功耗和时序目标不同

工程边界

OCC 只是测试基础设施的一部分。多时钟域、集成时钟门控（ICG）、PLL/分频器、低功耗电源状态和异步复位都可能改变测试协议。需要实际项目时，应从 DFT 规格、时钟约束、复位策略和工具 DRC 一起核对，而不是从示意动画生成插入命令。

Siemens 公开资料指出，Tessent ScanPro 包含 OCC 插入与自动化，并支持按时钟域、电源域和物理集群划分扫描链；参阅 Tessent ScanPro 官方介绍。Synopsys 的 TestMAX DFT 官方介绍也将扫描链、测试点、压缩和一致 DRC 放在完整 DFT 流程中讨论。

本页模型只展示门控状态与输出沿的因果关系，不表示已经完成真实 OCC 插入、时钟树收敛或芯片测试签核。

复核清单

真实项目应把 OCC 输出与时钟约束、复位约束、测试协议和 DFT DRC 一起复核；尤其要记录复位断言与释放的时序证据，并确认每个时钟域的 shift/capture 规则都已覆盖。

如果一个设计同时包含多个测试时钟源，应分别记录选择条件与互斥关系，避免把不同源的脉冲混在同一个简化波形里。

复位检查也应覆盖上电、测试模式切换和异常中断路径，而不只看一个复位复选框。
