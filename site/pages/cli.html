CLI 与 TUI

CLI 是终端中的 omp ...；TUI 命令是在已经启动的 OMP 输入框中键入 /...。工具如 wiki、task 由 Agent 调用，不是 Shell 命令。

日常启动参数

命令 用途 主要参数与影响
omp 在当前项目交互开发 默认可调用本会话可见工具
omp --cwd /path/to/project 指定项目目录 不搬移项目文件
omp --model <模型或角色> 使用已配置模型 模糊模型名、提供方/模型名按本地可用配置解析
omp -c 继续上一次会话 恢复该目录相关会话
omp -r 选择并恢复会话 也可接会话 ID 前缀或路径
omp -p "只读解释这个模块" 非交互执行后退出 -p 不自动限制工具为只读
omp --config /path/to/overlay.yml 本次启动叠加配置 不持久化覆盖层，可重复传入
omp --no-tools -p "解释所给文本" 只用所给文本回答 关闭内置工具，不读取代码仓
omp --approval-mode always-ask 覆盖本会话工具审批策略 自动允许读工具，写/执行按策略确认
omp --help 查该版帮助 无需模型推理

常用 TUI 操作

/switch 切换当前会话模型，/model 打开模型中心（这两项 TUI 行为参考上游 61fb07d，详见命令说明，不表示分发二进制已更新）；/settings 调整设置；/docs 查看索引；/agents 查看 Agent；/tools 查看当前工具；/context 查看上下文占用；/compact soft 压缩；/resume 恢复；/hotkeys 查看当前键位。

完整 TUI 清单在内置命令。每个命令页分别说明状态影响；不要仅根据名字推断其只读性。

CLI 注册入口

下面清单由固定版本 cli-commands.ts 提取。各入口的详细参数以该版 omp <入口> --help 为准；以下逐页给出用途、影响及入口示例。

名称 用途
omp launch 启动 OMP 会话（默认入口）
omp acp 通过标准输入输出运行 ACP 服务
omp auth-broker 管理凭据托管服务
omp auth-gateway 启动认证转发网关
omp agents 导出内置任务 Agent 定义
omp bench 测量模型延迟与吞吐
omp browser-relay 启动浏览器 CDP relay
omp cleanse 检测并修复项目诊断
omp commit 生成提交信息并更新变更记录
omp completions 输出 Shell 补全脚本
omp __complete 内部动态补全入口
omp compress 压缩文本文件为紧凑提示表达
omp config 读取和修改配置
omp docs 管理 Markdown Wiki 索引
omp dry-balance 模拟 OAuth 账户负载分配
omp gc 清理存储中的无用数据
omp grep 单独测试 grep 工具
omp gallery 展示确定性的 TUI 组件预览
omp git 打开全屏 Git 界面
omp grievances 查看、清理或推送工具问题报告
omp images 检查和管理图片发布后端
omp if-bench 测试指令遵循与工作记忆
omp install 安装或链接扩展包
omp join 加入实时协作会话
omp models 列出、搜索或刷新模型
omp plugin 管理插件安装与卸载
omp ps 查看与控制托管后台进程
omp say 使用本地 TTS 引擎合成并播放语音
omp share 生成会话分享链接
omp setup 首次配置模型服务
omp shell 交互式 Shell 控制台
omp read 显示 read 工具对指定资源的输出
omp render 通过真实渲染管线绘制会话线程
omp ssh 管理远程主机与连接
omp stats 启动本地统计仪表盘
omp sync-claude 同步 Claude 配置相关数据
omp update 更新 OMP 客户端
omp usage 查看模型提供方用量
omp tiny-models 下载会话标题和记忆用的本地小模型
omp token 获取提供方的 API key 或 OAuth token
omp ttsr 检查和测试时间回溯流规则
omp worktree 管理 Git 工作树
omp search 从 CLI 调用 Web 搜索

依据：启动参数。
