工作台/开始使用

omp render

通过真实渲染管线绘制会话线程。

示例

omp render --width 100 --plain

功能与场景

通过真实渲染管线绘制会话线程。

典型场景：维护 TUI 渲染。

主要参数

[session] 接受会话路径或 ID 前缀，省略时使用当前目录最近会话；--width / -w N 和 --height N 指定列/行，默认终端尺寸；--plain 去 ANSI；--timing / -t 输出计时；--repaint N 重绘测试；--quiet / -q 不打印正文。

以上为该固定版本的主要参数与使用条件；完整选项可用 --help 查看。

文件与状态影响

读取会话并输出渲染结果。

示例中的路径、链接与名称须按实际任务替换；涉及写入或远端操作时，请先确认操作对象与影响。
